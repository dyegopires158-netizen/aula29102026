# Videogames - Dyego Brayan Pires Farias da Rocha

Lê o array `dadosDyego` (produto, categoria, quantidade, preco) e exibe numa tabela,
com busca por nome, filtro por categoria e resumo de unidades e valor do estoque.

## Arquivos
- `dados.js` - o array
- `index.html` - estrutura
- `style.css` - aparência
- `script.js` - lógica (lê, filtra e exibe)

Abra o `index.html` no navegador.
